# AI车辆监控哨兵

实时交通与停车场智能分析系统

这是给值班/保安人员使用的桌面应用。打开后主要看三块：

- 左侧大画面：实时识别视频
- 右侧提醒：停车、车牌、运行速度
- 下方按钮：开始值守、停止、选择视频、打开记录

## 启动

双击：

```text
Start_SII_Traffic_App.bat
```

## 使用

1. 点击“选择视频”，选择要检查的视频。
2. 点击“开始值守”。
3. 识别画面会显示在左侧，不再弹出单独窗口。
4. 右侧会显示最新提醒、车牌结果和处理速度。
5. 需要结束时点击“停止”。

## 记录位置

每次运行的记录保存在：

```text
sii-exe\logs
```

包括：

- 程序运行记录 `run_*.txt`
- 车牌识别记录 `plates_*.csv`
- 停车记录 `parking_*.csv`
- 速度记录 `speed_*.csv`
- 起火烟雾记录 `fire_*.csv`
- 碰撞记录 `collision_*.csv`
- 可选的标注后视频 `annotated_*.mp4`

## 设置说明

普通使用只需要“选择视频”和“开始值守”。

下方设置给调试人员使用：

- 高性能 TensorRT：默认开启
- FP16 加速：默认开启
- 保存记录表：默认开启
- 保存标注视频：需要时再开启
- 碰撞提醒：需要检测人车接触风险时开启
- 起火烟雾检测：默认加载 `speedup-c\models\fire_smoke.onnx`，每秒检测一次
- 机器人通知：可选择飞书或企业微信，在“高级路径”里粘贴群机器人 Webhook；触发撞人或起火事件时实时推送
- 清晰度：默认 1280，越大越清楚但越吃显卡
- 限速km/h：超过这个速度会记录为超速，默认 45
- 车辆检测间隔：默认 3
- OCR间隔：默认 10
- 最多处理帧数：0 表示完整处理

高级路径一般不用改。应用会自动加载 TensorRT、CUDA、OpenCV 和 C++ 推理程序所需路径。

应用默认加载 `runs\annotations\traffic_gr0_line.json` 作为测速标定文件。换成别的视频时，
需要在“高级路径”里选择对应的测速标定文件，否则速度和超速不会生效。
